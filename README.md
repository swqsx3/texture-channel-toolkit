# 贴图通道工具箱

纯静态、零依赖的本地贴图通道处理工具。所有处理都在浏览器内完成，图片不上传、不联网。

## 运行

直接双击 `index.html` 即可（推荐 Chrome / Edge）。
若浏览器因 `file://` 限制导致导出异常，可在目录内起一个本地服务后访问 `http://localhost:8000`：

```
python -m http.server 8000
```

## 功能

### 拆分
1. 选择（或拖入）一张贴图，自动分离出 R / G / B / A 四个通道。
2. 每个通道可单独设置：**反相**、**水平翻转**、**垂直翻转**。
3. 通道预览支持灰度 / 彩色两种显示方式，导出时按当前显示方式输出。
4. 可单独导出某一个通道，也可一键导出全部四个通道。
5. **合成法线贴图**：任选两个源通道，分别指定它们落到法线图 RGB 的哪两个通道；
   剩下那个通道可选择填 `1`（255）或 `0`。法线图 A 通道固定为 255。

### 合并
1. R / G / B / A 四个槽位，每个槽位可以：
   - 放入一张贴图（可拖放到卡片上）；
   - 或用**自定义颜色 / 0-255 数值**直接填充（用于缺失的通道）。
2. 放入贴图后可选择从该贴图的哪个通道取值：R / G / B / A / 亮度。
3. 每个槽位独立支持反相、水平翻转、垂直翻转。
4. 输出尺寸默认取所有已载入贴图中的最大宽高，可手动修改。
5. 导出为 PNG（保留 Alpha）或 JPG（自动压白底）。

## 目录结构

```
index.html      界面骨架（首页 / 拆分 / 合并三个视图）
style.css       样式
js/core.js      像素读写核心：通道提取、反相翻转、合成、导出
js/split.js     拆分流程
js/merge.js     合并流程
js/main.js      视图切换与初始化
smoke-test.js   Node 环境下的核心像素逻辑自测（node smoke-test.js）
```

## 常见法线组合

| 用途 | 源通道一 | 源通道二 | 空余通道 |
| --- | --- | --- | --- |
| OpenGL 风格（+Y） | → R | → G | 填 1 |
| DirectX 风格（-Y） | → R | → G（勾垂直翻转） | 填 1 |
| 只有高度图 | 取 R 填 1，高度 → B | — | — |
